# Windows 11 桌面模拟器

这是一个中文、免安装的桌面模拟器，入口文件为 `win11模拟器.html`。桌面和交互仍由本地 HTML/CSS/JavaScript 驱动；应用图标使用 `assets/win11-icons/` 中的本地资源。

## 运行

保留目录结构，在 Windows 文件资源管理器中双击 `win11模拟器.html`，使用 Microsoft Edge 或 Google Chrome 打开即可。无需安装依赖、启动服务或联网。模拟设置、文件列表和记事本内容保存在当前浏览器的本地存储中；浏览器清除网站数据会一并清除这些演示数据。

## 交互

- 单击桌面图标选中，双击打开模拟应用；桌面空白处右键可打开快捷菜单。
- 点击任务栏 Windows 图标打开开始菜单；可切换“所有应用”或输入关键词搜索。
- 应用窗口支持拖动、双击标题栏最大化、最小化、还原和关闭；窗口最小化后可从任务栏恢复。
- 任务栏托盘提供快速设置、音量/亮度滑块、通知和日历；小组件按钮展开侧边面板。
- **文件资源管理器**：切换主页、此电脑和各文件夹；搜索当前目录；后退/前进；切换图标/列表视图；新建、重命名、删除模拟文件和文件夹。双击文本文件可在记事本中编辑。
- **设置**：侧边栏可切换系统、显示、设备、网络、个性化、应用、账户、时间语言、辅助功能、隐私和更新页面。亮度、音量、壁纸、深色/高对比度、Wi-Fi/蓝牙状态和用户名等设置可调整并在本地保存；“更新”仅改变演示状态。
- **记事本**：新建和切换多篇笔记、编辑自动保存、删除笔记、下载为文本文件；Ctrl+S 可提示保存状态。
- **计算器**：支持四则运算、百分比、正负号、平方、平方根、倒数、退格和键盘输入。

## 本地化软件模拟

微信、QQ、钉钉、百度网盘、腾讯视频、暴雪战网、WPS Office、搜狗输入法及 360 安全卫士都作为本地应用入口显示在桌面和开始菜单。系统图标取自随附的 `win11React-master.zip` 项目中的 `public/img/icon/` 资源；该项目随包提供 CC0 1.0 Universal 许可，许可文本随图标保存在 `assets/win11-icons/LICENSE-win11React.txt`。其余本地化图标由内嵌 SVG 绘制。应用入口数据由 HTML 中的 `apps`、`svgPaths` 和 `desktopApps` 维护。

这些软件入口展示各自名称和模拟首页，不是原厂客户端，不会连接真实账号或在线服务。文件资源管理器管理的是模拟文件系统，不会读取或修改 Windows 磁盘；设置不会更改宿主 Windows 的系统设置；更新、网络与安全扫描也都只改变页面内演示状态。
